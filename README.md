# Programação Modular

Repositório para a primeira atividade pontuada em laboratório (3 pontos) — variante Estação/Patinetes.

## Instruções

Faça o _fork_ do repositório original e o _clone_ de sua bifurcação para o computador do laboratório.

Resolva as questões conforme as instruções do enunciado.

Ao final, faça a **publicação de sua _branch_ com as respostas** e o **envio da URL do repositório na atividade do Canvas**.
